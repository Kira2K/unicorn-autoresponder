# Дата рождения легенды в HH Profile Filler

При подготовке Ru и En профиля сначала используется полная дата рождения из финального
CV. Она нормализуется в `YYYY-MM-DD`; даты работ для этого не нужны. Пустая строка,
пробелы и отсутствие значения означают, что дата рождения в CV не указана.

Только при отсутствии даты рождения в CV используется расчёт из опыта:
самая ранняя дата начала работы минус 18 календарных лет. Порядок записей и перерывы
в работе на расчёт не влияют. Например, `06/2018` даёт `2000-06-01`.

Если день не указан, используется первое число месяца; если указан только год —
1 января. Полная дата сохраняет месяц и день, кроме 29 февраля: в невисокосном
году рождения используется 28 февраля. Это условная дата легенды, а не реальная
дата рождения ученика.

Дата рождения из БД и столбец возраста легенды не используются. Подготовка
не меняет данные в БД и не требует миграции. Результат передаётся через
`PreparedProfile.cv.birthDate` существующему заполнению и проверке сохранённой даты
в HH. Повторное заполнение того же CV даёт ту же дату независимо от текущего года.

Если дата рождения в CV указана, но некорректна или даёт возраст вне диапазона 14–100
лет, подготовка останавливается с `profile_cv_birth_date_invalid`. Такое значение
нужно исправить в CV: его нельзя молча заменить расчётом. Поддерживаются полные даты
`YYYY-MM-DD`, `DD.MM.YYYY` и `DD/MM/YYYY`.

Если даты рождения в CV нет, подготовка завершается ошибкой
`profile_legend_birth_date_unavailable` до открытия HH, если опыта нет,
хотя бы у одной работы отсутствует корректная дата начала, дата
находится в будущем или расчёт даёт возраст старше 100 лет. Вместо неизвестной
даты нельзя незаметно подставить реальную дату рождения из БД или выбрать более
позднюю работу. Поддерживаются `MM/YYYY`, `MM.YYYY`, `YYYY-MM`, `YYYY`, `YYYY-MM-DD`
и полные даты `DD.MM.YYYY` / `DD/MM/YYYY` после извлечения из CV.

Эта политика уточняет правила источников HH Profile Filler только для даты рождения.
Заполнение по-прежнему запускается вручную для выбранного клиента и рынка.

Проверки: `npm run profile-filler:test`, `npm run typecheck`.
