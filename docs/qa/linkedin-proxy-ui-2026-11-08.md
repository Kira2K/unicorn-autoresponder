## Изменённый контракт

- Первый переезд и последующие замены используют общую проверку существующим
  `createProxyChecker`: работает, валидный выходной IP, совпадает страна ES/GE.
  При первом переезде страна берётся из анкеты, при заменах — из завершённого
  переезда. Ошибки/таймаут/неизвестная страна не ставят назначение в очередь.
- Обычный ученический `POST /api/octo/profiles/:id/proxy` применяет ту же политику
  к EN-профилю с переездом. История привязки не позволяет обойти её сменой аккаунта;
  первоначальный onboarding/continue для этого профиля также отклоняются.
  Экспертная настройка и остальные профили сохраняют прежний контракт.
- После проверки заново проверяются аккаунт, ревизия профиля и отсутствие доступа;
  SQL атомарно сохраняет очередь и доказательство. Повторные замены сохраняют ID,
  даты, паузу и состояние уведомления исходного переезда. Лимита замен нет.
- API возвращает только безопасные результаты: выходной IP и страны; реквизиты
  и исключения checker в ошибках не выдаются. Добавлен формат
  `USERNAME:PASSWORD@IP:PORT`, сохранены два прежних формата.
- Восстановлены пункты Юли 3–15: ссылка на инструкцию, предупреждение об одном дне,
  шаги 0–5, карточки стран, все шаги свёрнуты при загрузке, ограничения, поддержка,
  IP/страна проверки, завершение и падежи. Восстановлена подробная инструкция
  пересылки Outlook. Редактирование своего прокси и ограничения шага 4 сохранены.
- У Дениса завершение само перечитывает реальный закрытый EN-профиль и атомарно
  записывает квитанцию вместе со статусом. Отдельная кнопка подтверждения удалена.
  Незавершённое назначение, активный доступ, несохранённая форма, отсутствующие
  реквизиты LinkedIn и конкурентное изменение по-прежнему блокируют завершение.

Для этих изменений не нужна новая схема: последняя проверка хранится в JSON
существующей записи переезда. Установленные ранее миграции сохраняются.

Приёмник сохраняет связь с текущим аккаунтом, активирует «Пауза» на исходный интервал

Это подтверждает установленный SQL, но не запуск внешнего CRM-обработчика на проде.

учеников за последние 14 дней писем не найдено (только ограниченное
чтение метаданных, включая Spam/Trash). Это отсутствие доказательства доставки,

получение пересланных писем исключено из обязательного завершения этой работы.
