# LinkedIn: переезд на собственный прокси

Бизнес-правила: `contracts.mts`; процесс: `service.mts`; транзакции: `postgres-store.mts`.
Octo исполняет стандартный `proxyChange` через действующий worker. Нового worker нет.

## API

Только сессия ученика; client/account/profile ID выводятся на сервере.
Ответы `Cache-Control: no-store`. Реквизиты прежнего прокси и fingerprint не возвращаются.

- `GET /api/client/linkedin-proxy-move`: страна из анкеты, EN ID, состояние операции,
  `canReplace`, `canFinish`. Без ответа анкеты назначение запрещено.
- `POST .../proxy`: обычный `ProxyInput` (type/host/port/login/password/changeIpUrl).
  Один check соединения/страны, затем проверка прежней привязки и атомарная постановка
  операции в очередь. Страна должна быть ES/GE по анкете; город — инструкция.
- `POST .../finish`: `{countryChanged:true}`. Требует подтверждённого назначения того же
  operation ID и закрытого профиля с законченным доступом. Повтор возвращает прежнее завершение.

На аккаунт допускается один переезд. Повтор того же подключения продолжает операцию,
другое подключение не подменяет начатую. Неопределённый ответ читается обратно.
Блокированная операция передаётся поддержке, автоматического нового назначения нет.
После переезда в шаге 3 остаётся раскрытая штатная форма редактирования собственного
EN-прокси, включая ввод одной строкой. Повторные замены используют Octo proxy API;
завершённый переезд, его дата и уведомление не создаются заново. Замена доступна
после закрытия профиля и окончания доступа. Экспертный прокси по-прежнему заменяется
только через первоначальный переезд, его реквизиты ученику не раскрываются.
Для Dolphin сценария нет; завершённый переход ученика на Octo учитывается отдельно.
Кнопке нужны действующий LinkedIn, существующий EN-профиль Octo и назначенный прокси.
Профиль без прокси или ещё в очереди подготовки кнопку не открывает. Временный сбой
опроса сохраняет последнее известное состояние. При ошибке начальной загрузки переезда
вместо формы показываются объяснение и повторная загрузка.

## Данные и уведомления

Миграция явная, не выполняется при запуске. Таблица `noco.linkedin_proxy_move` хранит
привязку к конкретному аккаунту и EN, доказательство проверки, прежние реквизиты
приватно и событие завершения с `completedAt`/`pauseUntil` (+48 часов).
Удаление временного Octo-профиля сохраняет историю операции через nullable FK.

Завершение и постановка одного уведомления происходят в одной транзакции.
Доставка использует Bot API sendOne: claim → одна попытка → sent/failed/uncertain.
Неизвестная доставка автоматически не повторяется. Для роли «фейк» используется
`-5216637594`, для обычного ученика — менеджерские ботоотчёты с `@juliafeels fyi`.

CRM не подключена. `crmProxyPause` — тестируемая интерпретация события; отдельный
CRM-обработчик позже должен учитывать account ID/цикл, дедупликацию и точную границу 48 часов.
Переезд не вызывает автоматического изменения страны на сайте LinkedIn.

Запуск, тестовые входы, E2E и очистка: [локальный стенд](../local-console/README.md).
