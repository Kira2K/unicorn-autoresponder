# Границы данных LinkedIn Automation

| Система | Что в ней хранится |
| --- | --- |
| NocoDB | Карточки учеников |
| Источник резюме | Исходное резюме ученика; конкретное место хранения ещё не выбрано |
| База приложения | Привязки аккаунтов, настройки, задания, история и подтверждённые черновики |
| Dolphin | Профиль браузера и действующая LinkedIn-сессия |
| Unipile/LinkedIn | Текущее состояние аккаунта, профиля, связей, постов и комментариев |
| OpenAI API | Обработка переданного текста; не источник истины и не хранилище приложения |

## Основные связи

```text
studentId
  -> dolphinProfileId
  -> accountId
  -> настройки функций
  -> задания и история
```

## Правила

- Существующие таблицы NocoDB не меняются без отдельного решения.
- Куки используются только кратковременно внутри сервера.
- Полные ответы Unipile не сохраняются без необходимости.
- Резюме передаётся в OpenAI только для подготовки черновика профиля.
- Для ответа на комментарий передаются текст поста и нужная часть диалога.
- Куки, ключи API, исходные запросы к ИИ и полные ответы внешних сервисов не
  пишутся в логи.
