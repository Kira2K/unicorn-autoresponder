# Проверки моста

## Что подтверждено

- Очищенный Octo-патч проверен поверх актуального `master`: 212 регрессионных
  тестов, 15 проверок запуска и две headless UI-проверки прошли. TypeScript и
  production-сборка фронтенда прошли. Посторонние рабочие изменения не включены.
- Полный headless Console → HTTP gateway → агент E2E прошёл: два mock-клиента,
  три цикла, шесть имитаций native-снятия пароля и ни одного cloud clear.
  Для этого UI-стенда срок инъецирован как 45 секунд; рабочий срок остаётся
  120 секунд. Настоящий Octo, рабочие аккаунты и база в этом прогоне не используются.
- Контрактные тесты покрывают два клиента через три цикла, независимые сроки по
  120 секунд, сохранение паролей, перезапуски, потерю подтверждений и отсутствие
  повторных мутаций. Проверяются аккаунт, область профилей, force-stop и история.
- На Octo 3.1.3 расходный «Вася Пупкин TEST Ru»
  (`87cb1dedf24544538ec4b533f4eb92b7`) прошёл три последовательных live-цикла:
  защищённая выдача на 120 секунд, скрытие без остановки, запись synthetic
  cookie/localStorage после скрытия, обычное закрытие, снятие защиты мостом,
  открытие без пароля на этом ПК и проверка данных/UUID/fingerprint/storage/proxy.
  Пароль сохранён. Рабочая БД в этих опытах не использовалась.
- Проверены автономный ZIP без секретов, скрытый запуск Windows и штатная остановка.
- Локальные отчёты сохранены в `storage/octo-bridge-live-*.json`.

## Очистка реализации

Удалены локальный Console-стенд и его альтернативный runtime, UI-runner этого
стенда, облачная сравнительная матрица и диагностическое снятие пароля на втором
ПК. Остались рабочий мост, серверная интеграция, регрессии и проверка открытия
архива без пароля. Файловый адаптер перенесён в серверные тесты и не загружается
приложением. Приватные состояния, результаты и конфигурации сохранены.

## Что ещё требуется для production

- Первое открытие нового тестового профиля на свежем ПК после работы моста:
  без пароля, с проверкой saved markers и неизменного UUID. ПК, снявший пароль,
  не является свежим устройством проверки.
- Два одновременно работающих live-клиента через три полных цикла.
- Публикация серверной части и настройка четырёх приватных bridge-переменных
  на основном Render-сервисе. По проверке 22 октября 2026 серверные маршруты
  моста на нём ещё отсутствовали; HTML со статусом 200 не означает готовность.

Один профиль / три live-цикла и mock-проверки не заменяют эти условия.
Ранее повреждённые клиентские профили автоматически не восстанавливаются.
